# ReelCraft AI 🚀

An AI-powered social media content generator built using **IBM watsonx.ai** and the **IBM Granite Foundation Model**.

ReelCraft AI helps creators, students, marketers, and businesses generate engaging social media content from a single idea in just a few seconds.

---

## Features

- ✨ AI-generated captions
- 🎬 Video scripts
- 🏷️ Smart hashtags
- 🎨 Visual content ideas
- 📢 Call-to-action suggestions
- 📱 Supports:
  - Instagram
  - TikTok
  - LinkedIn
  - YouTube Shorts
- 🎭 Multiple content tones
- 📥 Download generated content

## How It Works

1. Enter your content idea.
2. Select the social media platform.
3. Choose a content tone.
4. Click **Generate Content**.
5. ReelCraft AI generates:
   - Caption
   - Video Script
   - Hashtags
   - Visual Concept
   - Call to Action
